# blog or not blog?

Personal blog, migrated from robertrv.wordpress.com. Published at https://robertrv.github.io
with GitHub Pages' built-in Jekyll build (theme: minima).

- New post: add `_posts/YYYY-MM-DD-slug.md` with `title`, `date` and optional `categories`/`tags` front matter.
- Images go in `assets/images/` and are referenced as `/assets/images/name.jpg`.
- Local preview (needs Ruby 3+, e.g. `brew install ruby`): `bundle install && bundle exec jekyll serve`
